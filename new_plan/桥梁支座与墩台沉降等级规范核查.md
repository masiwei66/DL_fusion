# 桥梁支座与墩台沉降等级规范核查

## 1. 核查结论

当前数据生成器中的：

```python
SUPPORT_RISK_THRESHOLDS_MM = {
    "warning": 0.5,
    "risk": 2.0,
    "danger": 5.0,
}
```

以及：

```python
SUPPORT_RISK_RANGES_MM = {
    "warning": (0.5, 2.0),
    "risk": (2.0, 5.0),
    "danger": (5.0, 10.0),
}
```

不是中国现行公路桥梁规范直接给出的统一沉降四级标准。它们目前只能解释为**数据集内部的合成状态分层**，不能在文档或论文中写成“依据中国规范确定的预警、风险、危险阈值”。

中国公路桥梁相关规范主要采用以下逻辑：

1. 按桥梁构件或部件评定技术状况标度；
2. 对墩台和基础检查均匀沉降、相邻墩台沉降差、水平位移、倾斜、滑移和发展趋势；
3. 以结构设计期望值或规范允许值作为控制基准；
4. 判断变位是否仍在发展，以及是否已经影响支座、桥面、伸缩装置和正常行车。

因此，当前数据集应同时保存：

- 连续沉降量；
- 相邻基础沉降差；
- 与规范允许值的比值；
- 沉降发展趋势；
- 规范语义等级；
- 用于机器学习采样平衡的合成严重度等级。

不能只保存一个固定的 `warning/risk/danger` 数值标签。

## 2. 适用的主要规范

### 2.1 《公路桥涵养护规范》JTG 5120—2021

交通运输部于 2021 年发布《公路桥涵养护规范》（JTG 5120—2021），自 2021 年 11 月 1 日起施行，同时废止 JTG H11—2004。该规范是运营期桥涵检查、养护和技术状况管理的主要依据。

它强调桥梁构件检查、技术状况评定和养护处治之间的衔接，但没有规定一个适用于所有钢筋混凝土桥、所有跨度和所有基础形式的“沉降多少毫米即预警/风险/危险”的统一四级表。

来源：交通运输部发布公告及规范下载页：

- [交通运输部关于发布《公路桥涵养护规范》的公告](https://xxgk.mot.gov.cn/jigou/glj/202108/t20210825_3616530.html)
- [《公路桥涵养护规范》（JTG 5120—2021）PDF](https://xxgk.mot.gov.cn/jigou/glj/202108/P020240129349058736824.pdf)

### 2.2 《公路桥梁技术状况评定标准》JTG/T H21

JTG/T H21 将桥梁技术状况按构件、部件、上部结构、下部结构、桥面系和全桥分层评定。梁式桥的主要部件包括上部承重构件、桥墩、桥台、基础和支座。也就是说，支座、桥墩和墩台基础在规范中是不同的评定对象，不能合并成一个简单的“支座沉降等级”。

规范总体技术状况采用 1～5 类，而不是 `safe/warning/risk/danger` 四级：

| 规范标度 | 规范语义 |
|---:|---|
| 1 类 | 技术状况良好 |
| 2 类 | 技术状况较好 |
| 3 类 | 技术状况较差，存在一般缺损或需要维修关注 |
| 4 类 | 技术状况差，存在较严重缺损或较快发展问题 |
| 5 类 | 技术状况危险，严重影响结构安全或正常使用 |

对桥墩位移，标准中的核心逻辑是：

- 标度 1：完好；
- 标度 2：该位移指标可以没有单独的中间描述；
- 标度 3：出现轻微下沉、倾斜或滑动，但发展缓慢或趋于稳定；
- 标度 4：出现下沉、滑动或倾斜，变形尚未超过规范值；
- 标度 5：基础或桥墩不稳定，沉降量超过规范值，或已经造成上部结构、桥面系变形过大。

对桥台位移，规范同样把“发展较快且尚未超过规范值”和“超过规范值、影响结构或不能正常行车”分开。

对基础沉降，标准中的沉降评定逻辑是：

- 标度 1：完好；
- 标度 3：轻微下沉，发展缓慢或趋于稳定；
- 标度 4：出现下沉，但沉降量小于或等于规范值；
- 标度 5：基础不稳定，下沉严重，沉降量大于规范值，并造成上部结构或桥面系变形过大。

这里没有把标度 2 强行对应为某个固定毫米范围，也没有给出 `0.5 mm、2 mm、5 mm` 这样的统一运营期阈值。

来源：

- [交通运输部公开的《公路桥梁技术状况评定标准》PDF](https://xxgk.mot.gov.cn/jigou/glj/202006/P020240521541427295157.pdf)
- [JTG/T H21—2011 下部结构评定条文转录页](https://jtg-h21.readthedocs.io/zh/latest/09.html)
- [JTG/T H21—2011 评定方法与等级分类](https://jtg-h21.readthedocs.io/zh/latest/03.html)

### 2.3 《公路桥梁承载能力检测评定规程》JTG/T J21—2011

该规程对基础变位检测给出了更直接的要求：

1. 检测基础竖向沉降、水平变位和转角；
2. 检测相邻基础沉降差；
3. 检测基础不均匀沉陷、滑移、倾斜等；
4. 判断基础变位是否趋于稳定；
5. 判断基础变位是否超出设计期望值；
6. 对于尚未稳定的基础变位，应设置永久观测点并定期进行控制检测。

对于简支桥梁，规程采用与相邻墩台最小跨径 `L` 相关的控制值。常见表述为：

```text
墩台均匀总沉降       <= 2.0 * sqrt(L) cm
相邻墩台均匀沉降差   <= 1.0 * sqrt(L) cm
墩台顶面水平位移     <= 0.5 * sqrt(L) cm
```

其中：

- `L` 为相邻墩台间最小跨径，单位 m；
- 当跨径小于 25 m 时，按 25 m 取值；
- 上述限值不包括施工过程中的沉陷；
- 对于超过上述限值且仍在继续发展的墩台或基础沉降，应采取相应加固处理措施。

换算为毫米：

```text
均匀总沉降限值     = 20 * sqrt(L) mm
相邻墩台沉降差限值 = 10 * sqrt(L) mm
水平位移限值       =  5 * sqrt(L) mm
```

例如，若相邻墩台最小跨径按 25 m 取值：

```text
均匀总沉降限值     = 100.0 mm
相邻墩台沉降差限值 =  50.0 mm
水平位移限值       =  25.0 mm
```

这些值是结构体系和跨径相关的控制限值，不是四级风险分界线。尤其不能把单个支座节点的强制 `UZ` 位移直接等同于相邻墩台基础的均匀总沉降限值。

来源：

- [JTG/T J21—2011 第 5.11 节桥梁基础与地基检测评定](https://jtgtj21-2011.readthedocs.io/zh-cn/latest/5.html)
- [JTG/T H21—2011 墩身位移评定及允许沉降注释](https://jtg-h21.readthedocs.io/zh/latest/09.html)

## 3. 支座与桥墩基础不能使用同一套沉降等级

### 3.1 支座

支座是桥梁的可更换部件，规范关注的重点包括：

- 支座脱空、偏压、剪切变形；
- 支座滑移、转动和错位；
- 橡胶老化、开裂、剥落；
- 钢板锈蚀、组件损坏；
- 支座功能是否仍然有效；
- 是否需要维修或更换。

支座技术状况主要依据支座类型和病害表现进行评定，不能简单地用基础沉降公式替代。

当前生成器中的：

```text
support_settlement_by_acquisition_mm
```

表示施加到支座/基础节点组上的参数化竖向强制位移。它是有限元状态参数，不等同于现场可直接测得的“支座病害量”，也不等同于墩台基础均匀总沉降。

### 3.2 桥墩和墩台基础

桥墩与墩台基础的沉降评定需要考虑：

- 均匀总沉降；
- 相邻墩台沉降差；
- 同一承台或基础不同点的不均匀沉陷；
- 水平位移、转角和倾斜；
- 变位是否继续发展；
- 是否已经造成支座、伸缩装置、桥面线形或正常行车问题。

因此，当前数据集中的：

```text
pier_1_foundation_a_settlement
pier_1_foundation_b_settlement
pier_2_settlement
multi_pier_settlement
differential_pier_settlement
```

应作为桥墩/基础状态族处理，并单独计算：

```text
absolute_settlement_mm
differential_settlement_mm
settlement_limit_mm
settlement_ratio_to_limit
settlement_trend
```

## 4. 对当前四级数据标签的判断

### 4.1 当前设置的问题

当前设置：

```text
safe       < 0.5 mm
warning    0.5 - <2.0 mm
risk       2.0 - <5.0 mm
danger     >=5.0 mm
```

作为**合成数据采样区间**可以使用，但存在三个问题：

1. 与 JTG/T H21 的 1～5 类技术状况标度不是一一对应关系；
2. 没有考虑桥梁跨径 `L`；
3. 没有考虑均匀沉降、差异沉降、发展趋势和结构影响之间的差别。

特别是对于最小跨径按 25 m 计算的简支梁桥，规范参考值为约 100 mm 的均匀总沉降限值和约 50 mm 的相邻墩台沉降差限值。由此可见，`5 mm` 不能直接解释为“规范危险线”；它更适合作为数据集中的早期异常或高敏感度危险档位。

### 4.2 推荐的标签分层

建议在 HDF5 中同时保留两套标签。

#### A. 规范锚定标签

该标签用于表达与规范相关的状态：

| 字段 | 含义 |
|---|---|
| `settlement_abs_mm` | 单个支座组、墩台或基础区域的绝对竖向变位 |
| `differential_settlement_mm` | 相邻墩台或基础之间的沉降差 |
| `settlement_limit_mm` | 根据桥型、跨径和适用规范计算的控制值 |
| `settlement_ratio_to_limit` | 实测/合成沉降量除以控制值 |
| `settlement_trend` | 稳定、缓慢发展、持续发展或快速发展 |
| `normative_condition_grade` | 规范语义标度，建议保留 1、3、4、5，并允许缺省 2 |
| `structural_effect_flag` | 是否造成桥面线形、支座、伸缩装置或正常行车影响 |

对于简支梁基础，建议按以下规则生成规范语义标度：

```text
grade 1:
    无明显沉降或处于正常基准范围

grade 3:
    有轻微下沉，但发展缓慢或趋于稳定

grade 4:
    出现下沉，仍不超过适用规范控制值，但发展较快或需要处置

grade 5:
    超过适用规范控制值，或基础不稳定，或已经造成明显结构/桥面影响
```

这不是把规范改写成固定毫米阈值，而是保留规范中“幅值 + 趋势 + 影响”的判定结构。

#### B. 数据集采样标签

该标签用于保证机器学习训练覆盖不同幅值区间：

```text
dataset_severity:
    0 = safe
    1 = warning
    2 = risk
    3 = danger
```

当前 `0.5 / 2 / 5 mm` 可以继续作为第一版数据集采样边界，但应在 manifest 中明确写成：

```text
severity_basis = "synthetic_sampling_bins"
severity_is_not_direct_normative_limit = true
```

同时增加规范比值：

```text
settlement_ratio_to_limit =
    abs(settlement_mm) / settlement_limit_mm
```

最终模型可以分别学习：

- 早期毫米级异常；
- 规范允许值以内但仍在发展的变位；
- 超过规范控制值或明显影响结构的高风险状态。

## 5. 对支座、墩台和局部桥面的具体建议

### 5.1 支座竖向位移

支座强制竖向位移属于支座/边界状态参数。建议继续保留 `support_settlement_by_acquisition_mm`，但不要直接称为“规范沉降等级”。

建议增加：

```text
support_displacement_mm
support_displacement_trend
support_functional_effect
support_dataset_severity
```

如果要与桥墩基础沉降建立关系，应另存：

```text
support_to_pier_kinematic_link
```

用来说明该支座位移是：

- 仅模拟支座局部竖向变化；
- 由墩台基础沉降传递而来；
- 作为组合状态同时施加。

### 5.2 桥墩/墩台基础沉降

桥墩和墩台基础应使用跨径相关的规范控制值，并至少区分：

```text
均匀总沉降
相邻墩台沉降差
同一基础组内差异沉降
水平位移
倾斜/转角
```

不能把 `pier_1_foundation_a` 和 `pier_1_foundation_b` 仅按两个节点组分别标记，而不计算两组之间的差异沉降。用户已经明确它们代表两个独立桥墩基础，因此两组之间的沉降差应成为一个独立的派生标签。

### 5.3 局部桥面沉降

局部桥面沉降不应直接套用墩台基础的 `2.0√L` 和 `1.0√L` 公式。它更适合使用：

- 局部区域最大沉降；
- 区域内沉降梯度；
- 相邻桥面节点差异沉降；
- 局部纵坡或折角变化；
- 是否引起桥面铺装、伸缩装置或行车舒适性问题。

因此，局部桥面标签应保留为独立状态族：

```text
deck_local_settlement
```

其 `dataset_severity` 可以与支座沉降使用相同的四级采样编码，但 `normative_condition_grade` 不应直接复用墩台基础等级，除非已经根据桥面结构设计限值或专项监测方案建立了明确映射。

## 6. 对生成器的修改建议

### 6.1 不建议立即删除现有四级标签

现有四级标签对于控制样本分布和训练任务仍然有用，不必立即删除。但应改名或增加元数据，明确其不是规范等级。

建议：

```python
DATASET_SEVERITY_LEVELS = ("safe", "warning", "risk", "danger")
DATASET_SEVERITY_BASIS = "synthetic_sampling_bins"
```

### 6.2 新增跨径相关控制值

建议在配置中增加：

```python
MIN_ADJACENT_SPAN_M = 25.0
SUPPORT_SETTLEMENT_TOTAL_LIMIT_COEFF_CM = 2.0
SUPPORT_SETTLEMENT_DIFFERENTIAL_LIMIT_COEFF_CM = 1.0
SUPPORT_HORIZONTAL_DISPLACEMENT_LIMIT_COEFF_CM = 0.5
```

对适用的简支梁桥：

```python
effective_span_m = max(min_adjacent_span_m, 25.0)
uniform_total_limit_mm = 20.0 * sqrt(effective_span_m)
differential_limit_mm = 10.0 * sqrt(effective_span_m)
horizontal_limit_mm = 5.0 * sqrt(effective_span_m)
```

实际工程中应优先读取桥梁设计资料和专项检测报告中的控制值，而不是无条件套用默认公式。

### 6.3 新增规范锚定数组

建议在 HDF5 中增加：

```text
/labels/support_settlement_limit_by_acquisition_mm
/labels/support_differential_settlement_by_acquisition_mm
/labels/support_differential_limit_by_acquisition_mm
/labels/support_settlement_ratio_to_limit_by_acquisition
/labels/support_settlement_trend_by_acquisition
/labels/support_normative_condition_grade_by_acquisition
/labels/local_deck_settlement_ratio_to_limit_by_acquisition
```

数组中的 `NaN` 或显式缺省值应表示“不适用或没有足够设计资料”，不能默认当作 0。

### 6.4 保留两种结论

生成器输出中应明确区分：

```text
dataset_severity
```

和：

```text
normative_condition_grade
```

前者服务于机器学习样本分层，后者服务于规范语义解释。两者不应互相覆盖。

## 7. 对当前数据集的最终判断

当前数据集的沉降分级可以继续用于下一步批量生成，但只能作如下表述：

> 当前 `safe/warning/risk/danger` 是面向参数化有限元训练数据的合成严重度分箱。它们用于控制沉降幅值覆盖和状态族平衡，不直接代表中国桥梁规范中的运营期技术状况等级或法定预警阈值。

当前数据集还缺少规范锚定的以下内容：

1. 按相邻跨径计算的均匀总沉降限值；
2. 相邻墩台沉降差限值；
3. 沉降与限值的比值；
4. 沉降发展趋势；
5. 桥面线形、支座功能和伸缩装置影响标记；
6. 支座局部位移与墩台基础沉降的语义区分；
7. 局部桥面沉降的独立评价基准。

因此，当前状态协议已经具备“机器学习标签分层”，但还没有完全具备“规范锚定的桥梁沉降监测标签”。
