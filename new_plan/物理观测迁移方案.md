# 前海7号桥参数化 FEM 反事实数据驱动的仿真—真实垂向 InSAR 状态迁移方案

> 总纲和 AI 输入/输出、数据角色、训练边界见：[研究总纲与 AI-数据契约](<研究总纲与 AI-数据契约.md>)。本文件负责方法路线和模型扩展。

## 0. 结论先行

前海7号桥数据已经足以把课题从“只有有限元数据的双模态分类”推进到“真实桥梁低频垂向形变异常筛查”。当前最适合人工智能硕士论文的主问题是：

> 在参数化 FEM 能生成带标签反事实状态、真实桥梁具有稀疏垂向 InSAR 和少量监测证据的条件下，如何学习可部署的桥梁区域状态表示，并将仿真域知识迁移到真实垂向观测。

论文的主输出应是**区域异常分数、形变重构、趋势变化和不确定性**。只有在获得可靠的巡检或维修标签后，才把输出扩展为具体构件损伤类别。

本文将 FEM 定位为**参数化反事实数据生成器**，而不是经过现场校准的高精度数字孪生模型。建议的方法名为：

**Physics-Observation and Uncertainty-aware Privileged Transfer Graph**（POUP-TG，物理观测与不确定性感知的特权迁移图模型）。

这里的创新重点不是重新发明 Transformer、GNN、MMD 或知识蒸馏，而是把它们组织成一个由 FEM 和 InSAR 观测机制共同约束的可验证模型。

### 最终研究目标

构建一条可复验的闭环：

```text
参数化 FEM 反事实状态
  -> 完整 FEM 桥面位移场归档
  -> 动态虚拟传感点采样、随机失活与噪声
  -> 可变点集源域状态学习/域适配
  -> 全部现有真实 PS 坐标、垂向 InSAR 与实际 mask
  -> 区域异常、风险排序、形变重构和不确定性
  -> JGC/Q/W/S 与工程事件窗口交叉验证
```

研究目标是验证“带标签的参数化 FEM 状态是否能够帮助真实垂向 InSAR 进行区域状态识别”，而不是证明 FEM 已经精确复现前海7号，也不是直接定量反演真实沉降参数。

### 推荐主线与可选扩展

1. **主线**：参数化热-静力 FEM、点位垂向观测算子、source-only/统计域适配、真实事件级验证。
2. **第二阶段**：质量权重、不确定性校准、传感器一致性和结构图编码。
3. **可选扩展**：动力 FEM 和振动特权教师。若动力边界、激励和阻尼缺乏可信依据，不纳入主结论。

## 1. 已核实的数据事实

### 1.1 前海7号真实垂向 InSAR 数据

文件：`前海7号桥PS点位数据（配准有限元后坐标）.xlsx`。

- 主表共 85 个桥面 PS 点，包含 `id`、FEM 坐标、`HEIGHT`、`VEL` 和形变时序。
- 形变列为 `D20250218` 至 `D20260730`，共 32 个时相，不是 20 个时相。
- 时序覆盖 2025-02-18 至 2026-07-30，列值单位看起来是 mm，`VEL` 为 mm/year。
- 已有 `X_FE_mm_check`、`Y_FE_mm_check` 和 `coord_status`，坐标已经配准到 FEM 平面坐标系。
- 55 个点标记为 `inside FE deck`，30 个点标记为 `outside FE deck`。这是原始点位的质量/角色字段，不再用于在读取阶段删除点。目标域保留全部85点，并由实际 mask、映射类型、映射距离和质量门控；外部点不能无条件当成桥面响应。
- 当前文件没有明确保存每个时相的相干性、位移标准差、解缠质量或缺测 mask；`D` 列的垂向正负方向、单位、参考日期和累计位移定义仍需从处理流程确认。
- 第一张表以 FE 坐标为主，第二张表是围护结构 PS 点，第三张表是少量参考点，三者不能在没有语义映射的情况下直接拼成同一个桥面序列。

这意味着当前真实目标域的有效输入近似为：

```text
d_insar: [T_target=32, P_real]    # 当前 P_real=85；仿真源域点数 K 动态变化
coord:   [P_real, 2]              # X_FE_mm_check, Y_FE_mm_check
height:  [P_real]
vel:     [P_real]
valid_mask: [T_target, P_real]
```

### 1.3 工程背景与可用事件

文件：`前海7号桥情况汇报.pptx`。

可作为目标域解释依据的事实包括：

- 2025 年 2 月现场巡查发现北端支座垫石水平位移，限位墩破损。
- 报告记录了既有路面裂缝，裂缝在 2021 年已经存在，不能直接把它当作 2025 年新异常。
- 监测报告记录：左线附近桥墩监测最大沉降约 -12.00 mm，右线附近约 -6.5 mm；桥面沉降点最大约 7.10 mm；桥梁位移最大约 -4.7 mm；桥墩位移最大约 -4.8 mm。不同指标的符号、参考面和时间不完全相同，不能直接混成一个标签。

论文应把这些信息作为**事件锚点和外部复核证据**，不能把 PPT 中的文字描述直接转换成逐时相、逐点的精确分类标签。

### 1.4 前海7号 FEM 模型

文件：`qianhai7_bridge_model_v3_shell.mac`。

模型的有效信息：

- 三跨布置为 50 + 80 + 50 m，总纵向长度约 180,000 mm。
- 桥面宽约 47,000 mm，FEM 坐标为 X 纵桥向、Y 横桥向、Z 竖向。
- 桥面使用横向加密的 SHELL181 等效平面，纵向约 1 m，横向约 0.5 m。
- 结构包含桥面壳、1#墩双圆柱、2#墩矩形墩、桥台和简化支承连接。
- 已定义 JGC07-1、JGC08-1、JGC09、JGC10、JGC11、JGC12 监测节点，并输出静力位移 CSV。
- 当前宏只完成自重和附加恒载静力求解，模态分析仍是注释状态，尚未实现与真实 InSAR 时间序列对应的温度场、多状态参数扰动或瞬态动力输出。

因此，它适合先做**热-静力结构响应和区域异常状态源域**，不应直接沿用旧数据集的材料 1–43、支座 221/513/395/687 和 2–40 Hz 激励设定。

### 1.5 当前数据库生成器与当前桥梁不匹配

文件：`dataset_generator_v2.py`。

当前生成器仍然：

- 指向 `STC_DATA/Exp_bridge` 和 `ansys_stc/Exp_bridge`；
- 使用旧项目的 43 个材料、6 个候选材料、4 个支座节点和旧测点 ID；
- 假设可以调用 `static_temperature_multi_steps` 和参考温度瞬态动力分析；
- 使用旧的动态结果节点 `[23, 67, 133, 155, 177, 645]` 和激励节点 `120`；
- 用旧 `safety_rules` 生成材料损伤、支座沉降、区域风险标签。

该生成器不能直接生成前海7号的有效训练数据。必须新建 Qianhai7 专用生成配置，或者把生成器拆成“桥梁模型适配器、工况采样器、结果导出器、标签/状态定义器”四层。

### 1.6 当前 JSON 与目标任务的差异

当前 `result_000000.json` 属于旧的温度状态协议：

```text
静态位移 [6, 6, 3]
动态加速度 [4000, 6, 3]
43 个材料缩放因子
4 个旧支座状态
旧区域风险标签
```

它可以作为代码和方法基线，不能作为前海7号的最终源域协议。前海7号源域必须保存完整桥面 FEM 位移场、桥面节点/单元集合和保序拓扑，使训练 loader 能为任意虚拟或真实传感布局复现插值观测。

## 2. 当前研究路径的优点与缺点

### 2.1 优点

1. **问题有真实工程牵引。** 前海7号存在支座位移、桥面沉降和长期 InSAR 形变，研究问题不是人为构造的分类任务。
2. **FEM 与真实 InSAR 坐标已经初步打通。** 85 个 PS 点均有 FE 坐标和55/30空间状态，可通过通用点集观测接口与桥面场建立映射。
3. **真实数据有独立监测证据。** 传感器数据能够用于验证 InSAR 的趋势和异常时段，避免论文只依赖伪标签。
4. **FEM 可以提供结构状态的受控反事实。** 通过改变温度、支座边界、局部刚度和土体/隧道作用，可以生成真实数据中难以获得的异常标签。
5. **研究边界比纯工程拟合更适合 AI 论文。** 仿真域标签、真实域弱标签、缺测和观测异构性能够形成明确的迁移学习问题。

### 2.2 缺点和风险

1. **真实样本量小。** 85 个 PS 点、32 个真实时相和一个桥梁案例不支持从零训练大型 Transformer，也不支持把点位当成独立样本做随机划分；其中桥面外点还需质量门控。仿真源域完整轨迹为26个子步，训练样本应按4、6、8期窗口及多种虚拟传感布局构造。
2. **真实标签弱。** PPT 和监测表能确认事件和趋势，不能为每个 PS 点提供精确构件损伤标签。
3. **垂向观测基准仍需核验。** 当前数据按垂向形变使用，不需要重新做 LOS 投影（当前数据不使用）；但仍需确认垂向单位、正负号、参考点/参考日期、累计位移定义和缺测规则。
4. **空间覆盖不完整。** 30 个点在 FE deck 外，部分点位坐标范围也可能包含道路或周边结构，必须按 `coord_status` 做样本分层。
5. **FEM 宏和生成器仍需补齐桥面集合语义。** 当前应稳定输出完整桥面场、桥面 component、温度时序和状态扰动库，并由训练 loader 动态生成虚拟观测；不再要求生成器固定输出55点 PS 数组。
6. **旧的材料损伤标签会造成语义错位。** 前海7号的主要已知风险是支座与沉降相关状态，继续使用旧桥的材料 ID 分类会让 AI 任务看似精确、实际不可验证。
7. **时间尺度不一致。** FEM 源域为 26 个连续年度温度子步，真实 InSAR 为 32 个不规则重访时相，传感器为月度累计量。必须先定义各自时间轴和参考基准，再按窗口协议做迁移。

因此，当前路径应该从“FEM 多任务安全分类”改成“参数化 FEM 反事实数据驱动的前海7号垂向 InSAR 区域状态迁移与异常筛查”。

## 3. 研究问题和论文边界

### 3.1 主研究问题

**RQ1：** 用完整 FEM 桥面场训练一个对传感布局、点数和缺测鲁棒的坐标感知点集模型，是否比固定真实 PS 布局训练或直接对齐 FEM 特征更能提高真实稀疏 InSAR 的形变重构和异常筛查稳定性？

**RQ2：** FEM 的全场位移和可选动力响应作为训练期特权信息、结构状态作为监督标签，能否提升只使用真实 InSAR 和监测数据的学生模型？

**RQ3：** InSAR 点质量、空间位置和传感器一致性是否能够让模型给出可校准的不确定性，并减少低质量点造成的误报？

### 3.2 推荐任务定义

训练期源域：

```text
(u_FE(x,y,z,T), mesh/region geometry)
    -> teacher embedding z_T, region state y
```

其中 `structural_parameters` 和 `y_state` 用于监督、分组和审计，不作为默认教师输入。

部署期目标域：

```text
(d_InSAR_vertical(t,p), point geometry, quality, sensor series)
    -> regional anomaly score, deformation reconstruction, uncertainty
```

主任务输出四类结果：

1. 每个 PS 点的异常分数；
2. 左端支座区、1#墩区、跨中区、2#墩区、右端支座区等区域分数；
3. 观测重构残差和趋势变化；
4. 置信度/不确定性以及“需要人工复核”的标记。

只有在后续得到可信事件标签时，才增加“支座异常/沉降/桥面异常”多标签头。材料级分类只保留为 FEM 受控实验，不作为真实桥梁主要结论。

## 4. 建议的算法模型：垂向 InSAR 状态迁移基线与扩展

### 4.1 核心思想

第一版不应预设复杂的 GNN、动态教师和多项损失同时上线。建议按“共同观测空间 → 简单基线 → 统计域适配 → 事件弱监督 → 可选特权教师/网络扩展”逐步实现。完整扩展模型可暂命名为 POUP-TG，但它不是第一阶段的必要条件。

核心组件为：

1. **布局可变的有限元观测算子**：训练时把完整 FEM 桥面场插值到随机虚拟传感点，推理时输入真实 PS；两者统一 UZ、坐标、参考基准、时间特征、质量和 mask 语义。
2. **源域到目标域的状态迁移**：源域使用 FEM 生成的带标签状态，目标域使用真实垂向 InSAR；先比较 source-only、统计对齐和简单学生模型。
3. **事件级弱监督**：利用 JGC/Q/W/S 和工程事件窗口进行验证或有限约束，不把它们直接当作逐点强标签。
4. **可选扩展**：在基础迁移成立后，再加入结构图、特权教师和不确定性感知门控。

论文启发在本方案中的准确落点是：源域使用带标签的 FEM-InSAR-like 观测，目标域使用无标签真实 InSAR；先对齐共同观测空间中的总体分布，再在目标域伪标签或区域条件足够可靠时进行条件分布对齐。不能把 FEM 动态振动直接与 InSAR 位移做 JDA，因为二者不是同一物理观测空间。

因此，训练数据流固定为两条学生路径和一条可选教师路径；每条路径内部的点数、布局和图结构仍可变化：

```text
FEM 桥面场 -> 动态 H_space(S)/失活/噪声 -> 可变点集源域 -> 学生编码器 z_s
真实 PS 坐标/观测/实际 mask ---------------------------> 学生编码器 z_t
FEM 静态位移 + 可选动态振动 ----------------> 特权教师 z_T

z_s/z_t: 源域监督 + 观测重构 + 域适配
z_T -> z_s: 仅训练期状态/区域/关系蒸馏
最终部署: 真实 InSAR -> 学生编码器 -> 输出
```

结构图、Transformer、蒸馏或 MMD 单独都只是基线组件；只有在消融实验中证明它们解决了明确失败模式，才保留为扩展模块。

### 4.2 观测算子

对任意传感点集合 `S={p_k}` 和日期 `t_j`，定义：

```text
u_FE(p_k, T_j) = Σ_e N_e(p_k) u_e(T_j)
d_FE→vertical(k,j) = u_z,FE(p_k,T_j) - u_z,FE(p_ref,T_j) + b_k + ε_kj
```

其中：

- `N_e` 是壳单元或三角/四边形单元的空间插值权重；
- `p_ref` 是与真实垂向 InSAR 处理一致的参考点或参考区域；
- `b_k` 是点位基准偏置；
- `ε_kj` 由质量、缺测和噪声模型控制。

实际实现分为训练和推理两个适配器，共用同一接口：

1. 训练适配器从桥面单元内动态采样可变数量的虚拟点，构造样本相关 `H_space(S)`，再加入随机失活、空间缺口、噪声和质量退化；
2. 推理适配器保留全部现有真实 PS 坐标和实际 mask，用同一插值/坐标语义构造输入，但不需要 FEM 场；两域分别按自身日期窗口化。

当前版本不虚构 LOS 单位向量、入射角或航向角。只有获得原始 InSAR 几何并重新处理数据时，才新增 垂向观测协议。

### 4.3 可选结构图

图节点分为三类：

- 观测节点：训练时为可变数量虚拟传感点，推理时为全部现有真实 PS 点；
- 监测节点：JGC、Q、W/S 点，按坐标映射或人工测点表定位；
- 区域节点：左端支座、1#墩、跨中、2#墩、右端支座等结构区域。

边由三部分组成：

```text
A = A_FE_topology + A_distance + A_sensor_region
```

- `A_FE_topology`：两个当前观测点落在同一壳单元或相邻单元时连接；
- `A_distance`：FE 坐标距离的局部 kNN 边；
- `A_sensor_region`：虚拟/真实观测点与其结构区域节点连接。

图边权由距离、结构区域和点质量共同决定。模型不应使用点的文件顺序作为空间关系。

### 4.4 可选教师—学生迁移

基础学生模型只使用真实部署可获得的数据。若后续启用特权教师，教师输入为：

```text
全场 FE 位移、温度响应、结构网格和区域定义
```

在动力模型经过边界条件、激励和阻尼审计后，教师可以增加同一 `structural_state_id` 下的 FEM 动态响应。该动态响应只用于学习更完整的结构状态表示，不与 InSAR 日期逐一配对，也不进入学生输入。

学生的核心输入为：

```text
垂向累计形变、真实/虚拟点坐标、日期间隔和 valid_mask
可选协变量：温度、HEIGHT、VEL/窗口趋势和可复算质量字段，并携带各自有效掩码
```

JGC/Q/W/S 传感器默认用于独立验证，不是主学生的必需输入。只有完成坐标、方向、基准和时间对齐后，才可在单独标注的扩展实验中增加传感器分支。

支承/刚度参数和区域状态标签属于监督、分组和审计字段。只有在明确标注的特权教师消融中才允许作为教师输入，不能进入最终学生模型，也不能与使用标签直接预测的结果混称。

教师输出结构状态嵌入 `z_T`、区域状态 `p_T` 和可观测位移 `d_T`。学生输出 `z_S`、`p_S` 和重构位移 `d_S`。

蒸馏只传递：

- 区域状态概率；
- 结构状态嵌入；
- 当前观测点之间的关系矩阵。

不传递 FEM 高频波形，也不要求真实 InSAR 具有高频加速度。教师必须先从响应中学习状态，再蒸馏状态层知识；不能把结构状态参数直接输入教师并将其预测当作蒸馏效果。若动力 FEM 没有可信边界条件，整篇论文可以不启用这一分支。

### 4.5 不确定性感知

为当前点集中的每个观测点学习观测方差 `σ_k^2`，并构造质量权重；训练时该点可以是虚拟传感点，推理时为真实 PS 点：

```text
w_k = valid_mask_k × mapping_quality_k × q_k
```

第一版的 `q_k` 可以由以下可复算量组成：

- InSAR 时序缺测率；
- 局部时空残差；
- `VEL` 的异常程度；
- 邻域一致性；
- 是否为桥面内插、最近桥面外推及其映射距离；
- 与传感器趋势的冲突程度。

获得相干性、位移标准差和解缠质量后，再把这些真实质量字段加入 `q_k`。不能把不存在的 coherence 字段伪造出来。

### 4.6 损失函数

扩展模型的主损失可写为：

```text
L = L_source
  + λ_obs L_observation
  + λ_state L_state_consistency
  + λ_priv L_privileged_distill
  + λ_domain L_state_conditioned_align
  + λ_sensor L_sensor_consistency
  + λ_unc L_uncertainty_calibration
```

其中域适配项只作用于共同观测空间编码后的 `z_s` 和 `z_t`，而不是原始 FEM 振动和 InSAR 位移。推荐把论文中的 JDA 思想实现为两个可独立开关的项：

```text
L_marginal_align = Dist(mean/cov(z_s), mean/cov(z_t))
L_conditional_align = Σ_c Dist(z_s^c, z_t^c)
```

`L_conditional_align` 的目标域类别只能来自高置信度伪标签、区域状态条件或经过冻结协议确认的弱证据，并且应设置置信度阈值、样本数量和停止条件，防止错误伪标签造成负迁移。MMD/CORAL/DANN 可分别实现或替代上述对齐项；JDA 作为论文方法参考和基线，不作为未经验证的默认主模型。

具体含义：

1. `L_source`：FEM 状态/区域标签监督，仅用于合成源域。
2. `L_observation`：动态 `H_space(S)` 作用后的虚拟观测与学生重构一致。
3. `L_state_consistency`：同一 FEM 结构状态在不同虚拟布局、点数、温度、失活和观测噪声下的 `z_state` 接近；条件信息进入 `z_condition`，避免把温度和真实变化全部抹掉。
4. `L_privileged_distill`：教师和学生的区域概率、嵌入和点关系蒸馏。
5. `L_state_conditioned_align`：只在相同区域/状态条件下对齐源域和目标域表示，MMD/CORAL/DANN 作为可替换实现和基线。
6. `L_sensor_consistency`：学生重构到传感器位置后，与独立监测数据的趋势和尺度一致；没有坐标映射的传感器先不参与该项。
7. `L_uncertainty_calibration`：使用质量权重、异方差重构和验证集 ECE/Brier 约束，使低质量点不会贡献过大的梯度。

建议第一版只启用 `L_source + L_observation`，并以 source-only、InSAR-only、MMD/CORAL/DANN 和温度/趋势基线建立参照。第二步加入无条件边缘对齐，第三步再加入条件对齐；确认事件窗口、传感器映射和质量字段后，才逐项加入 `L_sensor`、`L_unc`、特权蒸馏和结构图，避免一次引入过多不可验证机制。

每个模型变体必须记录：目标域样本用途、是否使用目标域标签、适配窗口、伪标签阈值、对齐层位置和是否启用教师。这样可以区分“无监督域适配收益”“弱监督收益”和“特权教师收益”。

## 7. 训练和实验路线

### P0：数据和坐标冻结

- 保留85个真实 PS 点、原始55/30状态及全部坐标，不在读取阶段删除点。
- 确认 D 列单位、垂向正负、参考点/参考日期、缺测规则和每个点的处理质量。
- 冻结桥面 component、保序单元拓扑和通用 `H_space(S)`；补齐全部真实点的映射类型、距离和垂向观测基准。
- 补充 2025-02 至 2025-11 的温度数据，优先与传感器重叠时段对齐。
- 建立 JGC/Q/W/S 与 FE 区域的坐标表。

### P1：完整 FEM 桥面场与动态虚拟观测

- 用 Qianhai7 FEM 生成健康和参数化异常状态。
- 归档26子步完整桥面场，不绑定真实 PS 点位。
- 训练 loader 通过动态 `H_space(S)` 生成不同点数、布局和窗口的模拟稀疏观测，并模拟失活、噪声、参考偏差和质量下降。
- 只使用 `structural_state_id` 做组级划分，同一状态的所有温度/扰动观测必须在同一集合。

### P2：源域基线

至少实现：

1. FEM 全场 source-only；
2. FEM 观测算子后的 source-only；
3. 真实 InSAR-only 自监督/异常基线；
4. 传统温度-形变回归和残差阈值法；
5. LSTM/TCN/Transformer 时序异常基线；
6. GNN 无观测算子基线；
7. MMD/CORAL/DANN 基线；
8. 普通知识蒸馏基线；
9. 完整 POUP-TG。

### P3：真实目标域迁移

- 学生模型的必需输入只包含真实 PS 坐标、垂向 InSAR 和实际有效掩码；温度与可复算质量作为带有效掩码的可选协变量。
- JGC/Q/W/S 传感器默认用于重叠窗口的独立验证，只有完成对齐后才进入单独的传感器扩展实验。
- 2025-02 至 2025-11 作为 InSAR/传感器重叠验证窗口。
- 2025-12 之后的 InSAR 只能用于无标签趋势和案例分析，不能假装有传感器真值。
- 2025 年 2 月支座异常、2025 年 8 月桥面沉降峰值等信息作为事件窗口，报告时间一致性和空间聚集性。
- 2021 年已有的路面裂缝作为历史背景，不作为新事件标签。

### P4：消融和鲁棒性

必须完成：

- 无垂向点位映射/参考基准处理；
- 无 FE 点位映射；
- 无温度条件；
- 无特权教师；
- 无状态条件对齐；
- 无质量权重；
- 无传感器一致性；
- 去除外部 30 个点；
- 人工增加缺测、噪声和参考点偏差。

### P5：真实案例报告

真实域应报告：

- 形变重构 MAE/RMSE、空间相关系数；
- 与 JGC/Q/W/S 监测趋势的相关性和时间滞后；
- 异常点的空间聚集和区域排序；
- 事件窗口的召回、提前量和误报数；
- ECE、Brier 或覆盖率等不确定性指标；
- 失败案例，尤其是 FE 外部点、长期基准漂移和季节温度未建模情况。

## 8. 与现有研究的差异

### 8.1 已有研究的主要路线

从当前收集的论文和研究笔记看，已有工作主要分为四类：

1. **PS/DS-InSAR 长期形变监测。** 重点是 PS 提取、相位解缠、时空形变和桥梁群筛查。
2. **InSAR + 温度的结构识别。** 通过温度-形变关系、TBSI 和更新 FEM 解释热变形，通常不训练跨域深度模型。
3. **FEM 与 InSAR/测量对比验证。** 用 FEM 解释空间趋势或核验 InSAR，但 FEM 不是带状态标签的教师域。
4. **深度学习异常检测或 SHM。** 使用 LSTM、Transformer 或基础模型处理监测时间序列，通常没有 FEM 观测算子，也没有真实部署端的特权模态约束。

### 8.2 本方案可主张的差异

可以主张的核心差异是：

> 现有方法通常把 FEM 当作离线校核工具，把 InSAR 当作独立时间序列，或直接在特征空间做域适应。本方案归档完整 FEM 桥面场，训练时动态采样虚拟传感点并加入失活与噪声，再用源域状态标签训练可变点集学生模型；部署时只输入真实 PS 坐标、垂向观测和实际有效掩码。观测质量用于模型内部降权，独立传感器只用于验证或单独标注的扩展约束。

这一差异必须由以下对照实验支撑，否则只能称为工程组合：

| 对照 | 要回答的问题 |
|---|---|
| 直接 FEM 特征对齐 vs 观测空间对齐 | 物理观测算子是否必要 |
| 普通蒸馏 vs 特权蒸馏 | 全场 FEM 信息是否真的帮助学生 |
| 无质量权重 vs 不确定性感知 | 质量控制是否减少误报 |
| 无 FE 图拓扑 vs 结构图 | 结构空间关系是否有增益 |
| 无传感器一致性 vs 有传感器一致性 | 独立监测是否提高真实案例可信度 |
| 温度回归基线 vs POUP-TG | 方法是否超出传统 TBSI |

### 8.3 文献对比的准确表述

可以参考和对比的本地资料包括：

- 周云等，`Temperature-based structural identification of long-span bridges using InSAR observation and meteorological shared data`，Advances in Structural Engineering, 2025，DOI: `10.1177/13694332251340715`。
- Lorenz 等，`Thermal deformation monitoring of a highway bridge combined analysis of geodetic and satellite-based InSAR measurements with structural simulations`，Journal of Civil Structural Health Monitoring, 2024，DOI: `10.1007/s13349-024-00779-9`。
- 周云等，`基于PS-InSAR技术的大跨度桥梁结构变形监测综述`，DOI: `10.6052/j.issn.1000-4750.2022.12.1069`。
- `基于星载InSAR技术的城市桥梁群结构变形识别与状态评估研究`：可作为桥梁群 InSAR 状态评估和层级指标体系对比。
- `Population-based structural health monitoring of bridges using spaceborne InSAR measurements`、`Spaceborne-InSAR monitoring framework for ... structural identification theory` 和 `Foundation Models for Structural Health Monitoring`：可作为群体监测、结构识别和深度模型基线的文献对比。

不要宣称“首次使用 InSAR、FEM、知识蒸馏或 GNN”。可主张的是**针对前海7号这类稀疏垂向观测提出参数化 FEM 反事实数据驱动的仿真—真实状态迁移机制，并用真实监测数据验证其可靠性**。

## 9. 论文创新点的建议写法

本节的创新点分层、证据要求和纯网络结构创新条件已进一步汇总于：[创新点汇总与论文定位](创新点汇总与论文定位.md)。

### 创新点一：物理观测空间迁移

构建从参数化 FEM 完整桥面场到可变稀疏点集时序的观测算子，联合处理动态虚拟传感布局、UZ 插值、参考基准、温度条件、失活和不规则重访；训练不绑定真实 PS 布局，推理时输入全部现有真实 PS，使源域和目标域在一致的点集观测接口中对齐。

### 创新点二：特权全场到稀疏观测的结构图蒸馏

训练期使用 FEM 全场位移作为特权信息、使用结构状态作为监督标签，部署期核心输入仅为真实 PS 坐标、垂向 InSAR 和实际有效掩码，通过区域状态、点关系和重构观测蒸馏学习可部署的结构状态表示。少量传感器默认只做独立验证；完成对齐后可作为单独扩展分支。结构参数只有在单独标注的特权输入消融中才进入教师，不能进入学生。

### 创新点三：质量和独立监测约束的不确定性迁移

把 InSAR 点质量、FE 内外状态、时空邻域一致性和传感器趋势冲突纳入异方差重构和图消息权重，输出区域异常分数和不确定性，并用监测数据验证质量降级时模型是否减少误报。

这三个点应作为一个统一方法写，不要把“GNN、Transformer、MMD、知识蒸馏、温度特征”各自包装成创新点。

## 10. 可行性判断和停止条件

### 10.1 可以继续推进的条件

- 能冻结完整桥面节点/单元集合和保序拓扑，通用 `H_space(S)` 对未见虚拟布局及全部真实 PS 坐标均通过插值/映射审计；
- 能补充至少一段与 InSAR 日期对应的温度数据；
- 能把 JGC/Q/W/S 点位映射到 FE 坐标或至少映射到区域；
- 能从 Qianhai7 FEM 导出全桥面位移场和参数化支承/刚度状态；
- 能把 2025-02 至 2025-11 的真实 InSAR 与监测数据按时间基准对齐。

### 10.2 必须降低论文主张的条件

- 没有可靠的垂向参考基准/单位：只能做受控相对形变实验，不能宣称与真实 InSAR 的绝对幅值一致。
- 没有全场 FEM 位移：只能做少数监测点回归，不能做 PS 点级观测迁移。
- 没有真实事件标签：只能报告异常筛查、趋势和复核线索，不能报告真实构件损伤准确率。
- 没有温度：只能把温度影响当作未建模扰动，不能声称完成温度-形变状态识别。
- Qianhai7 FEM 仍只有自重静力：暂时删除振动特权分支，把动态蒸馏留作扩展实验。

### 10.3 最小可发表版本

最小版本不依赖动态 FEM，包含：

1. Qianhai7 参数化热-静力 FEM 反事实生成器；
2. 完整 FEM 桥面场到任意坐标、可变点数观测集的垂向观测算子；
3. 观测空间 source-only、TBSI/回归、MMD/CORAL 和 POUP-TG 对照；
4. 真实 InSAR 与 2025 年传感器监测的趋势验证；
5. 质量、缺测、FE 外部点和温度消融。

动态振动和高频特权信息只有在 Qianhai7 FEM 完成模态/瞬态建模、并有可比较的监测信号后才加入。这样论文主线与现有实际数据一致，风险最低，算法贡献仍然完整。

第一阶段不要继续扩展旧 `DL_fusion` 的材料多任务头。先完成一条“Qianhai7 完整桥面场→动态虚拟传感点训练→全部现有真实 PS 推理→JGC/Q/W/S 监测证据”的闭环，论文的创新才有可审查的证据链。

### 11.1 四窗口与动态数据统一规则

完整 32 时相数据只作为轨迹级生成和审计对象。训练和部署样本由轨迹滚动切窗得到，支持 4、6、8 个获取时相，主窗口为 6，步长为 1。窗口内日期间隔直接作为模型条件输入，并保存窗口用途、事件匹配容差和窗口级标签。

FEM 结果分为归档层和动态训练视图。归档层保存网格、桥面集合、保序单元连接、全场三维位移、求解审计和可选动力结果；训练视图由 loader 对当前窗口动态生成虚拟点坐标、理想/参考后/加噪缺测观测、mask 和质量，不要求写回源 HDF5。动态响应保留但默认不启用，只能与同一 `structural_state_id` 关联，不得与真实 InSAR 做直接域对齐或强行日期配对。
