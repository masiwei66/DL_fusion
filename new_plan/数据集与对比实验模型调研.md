# 数据集与对比实验模型调研

> 调研对象：`new_plan` 中定义的“参数化 FEM 反事实状态 -> 真实垂向 InSAR 区域状态迁移”主线。
>
> 论文来源：`E:\working\my_project\具体工作\InSAR相关\论文\对比模型论文`，共 8 个 PDF。本文按 PDF 正文题名核对，不按截断文件名猜测。
>
> 结论先行：这些论文不能直接组成一张“论文结果横向比较表”。它们的桥梁、传感器、标签、采样率和任务不同。适合本项目的做法是提取其中可复现的模型机制/实验协议，在统一的 Qianhai7 FEM-InSAR-like 源域和真实垂向 InSAR 目标域上重建；论文原始结果只用于背景和方法依据。

## 1. 与当前项目的统一研究问题

本项目应回答：

> 带有结构状态标签的 FEM 反事实观测，能否帮助一个部署端只使用真实可获得的垂向 InSAR、点位几何、日期/间隔、温度、质量和有效掩码的模型，完成桥梁区域异常筛查、风险排序、形变重构和不确定性评估？

这里的“数据集”不是传统的真实损伤分类集，而是三层协议：

| 数据层 | 当前角色 | 可以支持的结论 |
|---|---|---|
| FEM 反事实源域 | 参数化健康、支座/桥墩沉降、局部沉降、刚度/支承变化等状态；提供标签和完整桥面场 | 源域监督、未见状态测试、观测算子和鲁棒性实验 |
| FEM-InSAR-like 源域 | 完整 FEM 桥面场经点位采样、`UZ` 提取、参考基准、日期/间隔、噪声、缺测和质量退化后形成 | 仿真源域到真实观测接口的一致化、source-only 和域适配 |
| 前海7号真实目标域 | 85 个 PS 点、32 个不规则时相（2025-02-18 至 2026-07-30），其中 55 个 FE deck 内、30 个外部点 | 真实推理、区域/事件级验证和失败案例；没有逐点强损伤标签 |

传感器和工程资料是独立验证或事件级弱监督：不能把月度累计传感器值、支座异常记录或工程事件窗口直接改写成逐点、逐时相真值。材料参数、支座沉降真值、FEM 状态 ID 只能用于标签、分组和审计，不能进入部署端学生模型。

## 2. 数据集分析与公平比较原则

### 2.1 训练、适配和测试边界

1. FEM 按 `structural_state_id` / 状态族划分；同一状态的温度轨迹、观测实现、噪声副本和滚动窗口不得跨集合。
2. 目标域明确分为 `adaptation`、`validation`、`final_test`。无标签目标域只能在 adaptation 中用于域适配；阈值、损失权重和校准只由 validation 决定；final test 冻结后只评估一次。
3. 最终主结果使用相同 split manifest、相同训练预算和 5 个种子：`13, 29, 42, 71, 101`。
4. 归一化统计量只由训练集估计。所有方法使用同一观测字段白名单，禁止把状态真值或标签泄漏到模型输入。
5. 需要分别报告未见结构状态、未见虚拟点布局/点数、未见噪声/缺测条件和真实目标域结果；不能把随机切分的温度步或观测副本当作泛化证据。

### 2.2 主输入与评价指标

部署端主输入统一为：

```text
垂向 InSAR 位移、PS 坐标/高程、获取日期或日期间隔、valid_mask、可获得的质量字段
可选：温度及其有效掩码、VEL/窗口趋势、FE 内外或映射距离
```

不作为学生输入：FEM 全场位移、支座/刚度真值、结构状态标签、动力响应或现场传感器真值。动力 FEM 若启用，只能作为训练期特权教师。

建议指标：

- 区域异常：AUCPR/AUROC、事件窗口 recall、误报数、提前量、空间聚集性；
- 状态/风险：macro-F1、balanced accuracy、weighted Kappa、等级 MAE；
- 形变重构：MAE、RMSE、趋势相关系数、空间相关性；
- 可信度：ECE、Brier、NLL、预测区间覆盖率；
- 域适配诊断：源域到目标域的性能下降、域分类准确率、负迁移比例。

## 4. 推荐的正式对比实验矩阵

### 4.1 第一层：最低工程和数据基线

1. **先验/常数基线**：训练集区域风险 prevalence、全健康预测、趋势最后值。
2. **温度基线**：逐点或逐区域 `d(t) = a + bT(t) + trend(t)`；增加分段线性、Huber/Theil-Sen 或温度残差阈值。
3. **FEM 观测拟合**：在同一个 `FEM-InSAR-like` 观测空间中，用最小二乘/最近状态/候选状态集合检索，不强制输出唯一损伤原因。
4. **FEM 参数更新基线**：参考 Zhou-TBSI，先实现简化温度-FEM 响应拟合；有可靠温度场和参数化状态后，再加入 DE。
5. **统计特征模型**：趋势、差分、季节幅值、空间均值/方差、质量比例 + Logistic/Random Forest/Gradient Boosting。

### 4.2 第二层：InSAR-only 时序模型

统一读取垂向位移、坐标、日期/间隔、温度、质量和 mask，只改变编码器：

| 模型 | 作用 |
|---|---|
| 线性/MLP | 判断是否只需趋势和低阶统计特征 |
| GRU/LSTM | 非图时序基线，参数量较小 |
| TCN/1D CNN | 局部时间模式基线，也最接近桥梁 InSAR 迁移类论文的实现形态 |
| 轻量 Transformer | 长时依赖对照，控制参数量，不能默认更强 |
| DLinear/PatchTST | 分别作为简单线性和 patch 时序参照；仅在数据量足够时加入 |
| GCN/GraphSAGE/GAT/STGCN | 空间关系和时空图对照；固定点数时使用 padding/mask 或集合池化 |

真实目标域没有逐点强标签时，这一层主要在 FEM-InSAR-like 源域做源域能力、未见状态和鲁棒性评估；真实域只报告区域/事件级验证。

### 4.3 第三层：仿真到真实的域适配

固定学生编码器、输入字段、优化预算、split 和随机种子，只改变域适配方式：

```text
DA0  Source-only
DA1  CORAL / MMD
DA2  NCA / NCORAL 风格统计对齐
DA3  DANN / 对抗域判别器
DA4  条件 MMD / JDA 风格对齐（仅高置信目标伪标签或可靠区域条件）
DA5  物理观测算子 + DA1-DA4
```

每个 DA 模型至少做以下二维消融：

```text
原始 FEM/固定特征空间对齐
vs
完整观测空间：FEM 全场 -> 动态点位 -> UZ -> 参考基准 -> 日期/间隔 -> 噪声/缺测/质量
```

这样才能回答“提升来自域适配，还是来自正确的 FEM 到 InSAR 观测转换”。MMD、CORAL、DANN、JDA 和 NCORAL 本身都是成熟基线，不能单独包装为网络创新。

### 4.4 第四层：特权信息和蒸馏扩展

只在动力 FEM 的边界、激励和阻尼经过审计后加入：

1. **No-teacher**：InSAR 学生单独训练。
2. **普通 KD**：教师读取训练期 FEM 响应，学生读取 InSAR；蒸馏状态概率/嵌入，不传递真值参数。
3. **Generalized Distillation/LUPI**：教师可以看完整 FEM 桥面场或动力响应，学生只能看部署输入。
4. **关系/区域蒸馏**：蒸馏区域 token、点关系和可观测位移重构，不蒸馏真实 InSAR 不具备的高频波形。

若动力 FEM 未完成可信审计，删除这组主结论，只保留“无动力特权教师”的最小主线。

## 5. 最小可发表对比包

建议按下面顺序实现，避免一次堆入所有网络：

```text
1. 常数/先验 + 温度趋势回归 + FEM 观测拟合
2. InSAR-only：MLP/GRU/TCN
3. FEM-InSAR-like source-only
4. CORAL/MMD、NCA/NCORAL、DANN
5. 物理观测算子 + source-only/DA
6. 无教师、普通 KD、特权状态/关系 KD（可选）
7. 质量/mask/区域层级模型及针对性消融
```

正式主表至少包含：

| 编号 | 模型 | 是否建议进入主表 | 原因 |
|---|---|---|---|
| B0 | Prevalence/Dummy | 是 | 最低水平与类别不平衡参照 |
| B1 | 温度趋势/残差模型 | 是 | 排除热变形解释不足 |
| B2 | FEM 观测拟合/候选状态检索 | 是 | 直接物理匹配参照 |
| B3 | 统计特征 + RF/Logistic | 是 | 非深度学习上限 |
| D0 | InSAR-only MLP/GRU/TCN | 是 | 部署端时序能力参照 |
| DA0 | FEM-InSAR-like source-only | 是 | 衡量真实域分布落差 |
| DA1 | CORAL/MMD | 是 | 低复杂度边缘分布适配 |
| DA2 | NCA/NCORAL | 建议 | 应对目标域类别不完整和不平衡 |
| DA3 | DANN | 是 | 对抗域适配参照 |
| DA4 | 条件 MMD/JDA | 第二阶段 | 需要高置信目标条件，防止伪标签负迁移 |

| KD | FEM 特权教师 -> InSAR 学生 | 可选 | 动力/FEM 可信且蒸馏边界清楚时加入 |

## 6. 不能进行的横向比较

以下比较会导致结论失真，应在论文中明确避免：

- 不能把 TBSI 的“损伤参数误差约 5%”与本项目的事件召回、AUCPR 或区域风险 F1 直接排排名次；
- 不能把 Giglioni、Gardner、Yano 等振动 SHM 的跨桥分类准确率与 InSAR 区域异常结果直接比较；
- 不能把 FEM 动力响应教师的性能当作真实 InSAR 学生的部署性能；
- 不能把目标域事件记录、传感器趋势或工程报告直接当作逐 PS 点强标签；
- 不能把 30 个 FE deck 外点无条件当作桥面结构点；应保留并作为质量/映射消融；
- 不能按时相、测点或噪声副本随机切分；同一 `structural_state_id` 必须绑定在同一集合；
- 不能只报告融合模型最好的材料/支座任务；需要同时报告区域、全桥、重构和校准结果，并保留负结果。

## 7. 当前执行结论

### 必做

1. 以 Zhou-TBSI 风格温度/FEM 解释作为强物理基线。
2. 以 FEM-InSAR-like source-only 为源域深度基线。
3. 实现 CORAL/MMD、NCA/NCORAL 和 DANN 三类 DA 对照。
4. 统一做“无观测算子 vs 有观测算子”的消融。
5. 真实目标域只做区域/事件级验证，使用传感器趋势、工程事件和不确定性指标。
6. 纠正 `on-statistic-alignment...pdf` 的错误文件名，并补入真正的 Poole 统计对齐论文文件，避免引用错文献。

### 暂缓

- CycleGAN/物理 GAN：实现成本和伪形变风险较高，放在 DA 基线完成之后。
- 动力特权蒸馏：等待 Qianhai7 动力边界、激励和阻尼审计完成。
- 大型 Transformer、PatchTST 和复杂 STGNN：先完成 TCN/GRU/简单图网络，再按数据规模决定。
- 纯网络结构创新：只有完成排列等变、缺测隔离、质量降权、结构级消融和未见布局测试后，才可正式主张。

### 最稳妥的论文闭环

```text
参数化 FEM 状态
  -> 完整桥面场
  -> 动态虚拟点位、UZ、参考基准、日期/间隔、噪声和质量
  -> source-only / CORAL-MMD / NCORAL / DANN
  -> 全部真实 PS 点推理
  -> 区域异常、形变重构、不确定性
  -> JGC/Q/W/S 与工程事件窗口独立验证
```

这个闭环与当前 `new_plan` 的数据角色一致，也能把目录内论文真正转化成可复现、可公平解释的对比实验，而不是简单罗列论文名称。

- `A domain adaptation approach to damage classification with an application to bridge monitoring`：Giglioni et al.，MSSP 209 (2024) 111135，正文摘要明确为源域/目标域桥梁动态特征域适配。

## 9. 对比模型适用性最终判断

本节是在前述逐篇阅读基础上，对“是否适合作为本研究对比模型”作出的最终筛选。判断标准不是论文是否使用了深度学习，而是：输入是否与部署端垂向 InSAR 可对应，源域/目标域设定是否可重建，监督粒度是否与本项目的区域/事件级任务一致，以及是否能够在同一数据协议下公平比较。

### 9.1 适合进入正式主表

| 模型 | 适用性 | 适合作为对比的原因 | 实施边界 |
|---|---|---|---|
| Prevalence/Dummy | 必须 | 提供类别不平衡条件下的最低水平 | 只使用训练集先验，不读取任何目标域标签 |
| 温度趋势回归/温度残差阈值 | 必须 | 检验模型是否只是利用温度解释热胀冷缩 | 逐点或逐区域建模；需要保留温度缺失掩码 |
| TBSI/FEM 物理拟合 | 必须 | Zhou 等论文与本项目的温度、InSAR、FEM 机制最接近，是强物理基线 | 先做线性回归和候选状态拟合；DE 参数更新放在温度和 FEM 审计通过后 |
| InSAR-only 线性/MLP | 必须 | 判断趋势和低阶统计特征是否已足够 | 只能使用垂向 InSAR、坐标、日期、温度、质量和 mask |
| InSAR-only GRU/LSTM/TCN | 必须 | 提供部署端普通时序模型基线 | 与主模型使用相同输入、窗口、参数量级和训练预算 |
| FEM-InSAR-like Source-only | 必须 | 直接回答无域适配时 FEM 标签能否迁移到真实 InSAR | 目标域不参与训练；真实域只做冻结后的推理/验证 |
| Source-only + CORAL/MMD | 适合 | 标准无监督边缘分布对齐，适合 FEM 有标签、真实 InSAR 无强标签的设定 | 只能在共同 InSAR-compatible 表示上对齐，不能直接对齐 FEM 三维场与真实位移 |
| Source-only + DANN | 适合 | 提供对抗式域适配对照，检验是否优于显式统计对齐 | 报告域分类准确率、目标域性能和负迁移，不只报告训练损失 |
| 物理观测算子 + Source-only/DA | 必须作为主方法骨架 | 验证 FEM 全场到点位、`UZ`、参考基准、日期、噪声和缺测转换是否带来增益 | 必须与“无观测算子”版本成对比较 |

其中，`FEM-InSAR-like Source-only`、`CORAL/MMD`、`DANN` 和“物理观测算子 + DA”是本研究仿真到真实迁移主线的核心对比；温度/TBSI 和 FEM 观测拟合是不可省略的物理参照。

### 9.2 适合第二阶段扩展

| 模型或论文路线 | 适用性 | 为什么不作为第一阶段主模型 |
|---|---|---|
| NCA/NCORAL/统计对齐 | 建议加入 | 适合处理类别不平衡和 partial DA，但需要先明确目标域正常参考窗口和 adaptation/validation/test 边界 |
| 条件 MMD/JDA | 建议加入 | 需要高置信目标伪标签、区域条件或可靠工程弱证据；过早使用容易产生伪标签负迁移 |
| Giglioni 等桥梁域适配协议 | 适合作为协议近邻 | 原论文使用固有频率/振动特征和损伤类别，应在本项目上重建，不能直接复用原始特征或结果 |
| Fernandez-Navamuel 等 FEM 监督深度学习 | 适合作为 FEM 源域监督依据 | 原文主要使用动态响应；可重建为 FEM-InSAR-like source-only，但不是同一输入任务 |
| 统计特征 + RF/Logistic/Gradient Boosting | 建议加入 | 作为非深度学习上限很有价值，但应在主线数据协议稳定后加入 |
| GCN/GraphSAGE/GAT/STGCN | 建议加入 | 用于判断空间图和时空图是否有增益；需要解决可变点数、缺测和参数量公平性 |
| 普通 KD/状态蒸馏/区域关系蒸馏 | 可选 | 只有动力 FEM 或完整 FEM 教师的输入边界、监督边界和可部署学生接口明确后才有意义 |

### 9.3 暂不纳入正式主表

| 模型或论文路线 | 暂不纳入原因 |
|---|---|
| 物理约束 CycleGAN/生成式域适配 | 原论文物理约束针对动力响应方程，不等同于 InSAR 空间观测算子；生成器还可能引入难以审计的伪形变 |
| 大型 Transformer/PatchTST | 当前真实目标域规模和标签粒度不足，先完成 TCN/GRU/轻量模型；复杂模型应作为容量受控扩展，而非默认主基线 |
| 动力特权教师 | Qianhai7 动力边界、激励、阻尼和真实对应关系尚未完成审计；动力响应不能直接作为学生输入 |
| Bucinskas 等 AR/FFT 频谱方法 | PDF 正文是 Vilnius 桥振动频率提取，不是统计对齐；可作旧动态分支工程基线，但与低频垂向 InSAR 主任务不对应 |
| Zinno 等 AI-SHM 综述 | 综述不是可执行模型，只用于模型谱系、指标和研究背景 |
| Yano 等跨桥迁移学习 | 适合支撑结构相似性和迁移边界分析，但不是一个可直接放入本项目主表的单一模型 |

### 9.4 推荐执行顺序

```text
阶段 1：
Dummy
-> 温度趋势/残差
-> FEM 观测拟合
-> InSAR-only MLP/GRU/TCN
-> FEM-InSAR-like Source-only

阶段 2：
Source-only + CORAL/MMD
-> 物理观测算子 + CORAL/MMD
-> Source-only + DANN
-> 物理观测算子 + DANN

阶段 3：
NCA/NCORAL
-> 条件 MMD/JDA
-> 质量感知/区域级主模型

阶段 4，可选：
普通蒸馏
-> 特权状态/关系蒸馏
-> 物理约束生成式迁移
```

这样可以依次回答：传统温度解释是否足够、FEM 源域是否可迁移、观测算子是否必要、统计/对抗域适配是否有效、质量和区域建模是否进一步改善结果。不要在第一轮同时引入域适配、蒸馏、复杂图网络和生成式模型，否则无法归因性能增益。

## 10. 公平性与不可直接横向比较的结果

以下结果不能直接放在同一列进行性能排名：

- TBSI 论文的“损伤参数误差约 5%”不能直接与本项目的 AUCPR、事件召回率或区域风险 F1 比较；
- Giglioni、Gardner、Yano 等振动 SHM 的跨桥分类准确率不能直接与本项目的 InSAR 区域异常结果比较；
- FEM 动力教师的性能不能当作真实 InSAR 学生的部署性能；
- 工程事件、传感器趋势和报告记录不能直接当作逐 PS 点、逐时相强标签；
- 30 个 FE deck 外点不能无条件当作桥面结构点，应作为质量、映射或排除点消融；
- 不能按时相、测点或噪声副本随机切分；同一 `structural_state_id` 必须绑定在同一集合；
- 不能只报告融合模型表现最好的材料或支座任务，应同时报告区域、全桥、重构、校准和失败案例。

所有正式对比应共享同一 split manifest、输入字段白名单、归一化统计量规则、训练预算、5 个随机种子和测试协议。真实目标域结果应主要采用区域异常、事件窗口召回、误报数、提前量、趋势一致性和不确定性校准，而不是伪造逐点损伤准确率。

## 11. 最终结论

**适合作为本研究正式对比模型的核心方法**是：

1. 温度趋势/TBSI/FEM 物理基线；
2. FEM-InSAR-like Source-only；
3. InSAR-only 的线性、MLP、GRU/LSTM、TCN；
4. CORAL/MMD；
5. DANN；
6. 物理观测算子前后的成对对照。

**适合作为第二阶段扩展**的是：NCA/NCORAL、条件 MMD/JDA、统计特征树模型、轻量图网络、Giglioni 风格域适配协议和 FEM 特权蒸馏。

**不适合当前主表**的是：物理 CycleGAN、大型 Transformer/PatchTST、未经动力审计的特权教师、AR/FFT 振动频谱方法、AI-SHM 综述以及 Yano 跨桥迁移路线作为单一模型。

因此，主实验最小闭环应固定为：

```text
温度/FEM 物理基线
-> InSAR-only 时序基线
-> FEM-InSAR-like Source-only
-> CORAL/MMD 与 DANN
-> 物理观测算子 + Source-only/DA
-> 真实 PS 推理
-> 区域异常、形变重构、不确定性和事件级验证
```

这套筛选与 `new_plan` 的研究目标、部署输入和真实标签粒度一致，能够回答本研究真正关心的问题，而不是简单把其他桥梁 SHM 论文的模型名称全部堆入对比表。

## 12. 有限元数据训练深度学习模型的补充检索

### 12.2 适合进入正式主表的 FEM 深度模型

论文名称不应直接等同于实验模型。正式实验应固定同一 FEM-InSAR-like 数据接口，只改变模型机制：

| 编号 | 统一模型名 | 推荐定位 | 必要约束 |
|---|---|---|---|
| FEM-DL-1 | `FEM-InSAR-like MLP/ANN source-only` | **正式主表，优先级最高** | 依据 Lee et al. 2023 的 FEM 生成状态数据 + DNN 识别路线；输入必须改为垂向 InSAR、坐标、日期、质量和 mask |
| FEM-DL-2 | `FEM-InSAR-like 1D CNN/TCN source-only` | **正式主表** | 与 MLP 使用同一窗口、同一状态划分、同一训练预算；只比较时序局部模式建模能力 |
| FEM-DL-3 | `FEM-InSAR-like GRU/LSTM source-only` | **正式主表** | 作为普通时序模型对照；控制参数量和训练轮次 |
| FEM-DL-4 | `FEM-InSAR-like MLP/TCN + CORAL/MMD` | **正式主表** | 只在共同 InSAR-compatible 表示上对齐，目标域 final test 不参与调参 |
| FEM-DL-5 | `FEM-InSAR-like MLP/TCN + DANN` | **正式主表** | 同时报告域分类准确率、目标域性能和负迁移比例，不能只报告对抗损失 |
| FEM-DL-6 | `FEM-InSAR-like sparse-to-field CNN/GNN` | 第二阶段 | 完整 FEM 场只作为标签或辅助任务；学生输入仍是稀疏 InSAR-like 点集 |
| FEM-DL-7 | `FEM-InSAR-like GCN/GAT/GraphSAGE` | 第二阶段 | 支持可变点数、缺测隔离、空间邻接审计和参数量公平 |
| FEM-DL-8 | `FEM teacher -> InSAR student KD` | 可选扩展 | 教师只能传递状态、区域或关系表示，不能传递支座沉降真值、刚度缩放因子或完整场答案 |

### 12.3 适合第二阶段但不应抢占主线的模型

1. **FEM 场重构 CNN/GNN**：用于回答“稀疏 InSAR 是否能重构合理的 FEM 垂向场”。评价应使用 MAE、RMSE、空间相关性和区域误差，不能把场重构误差直接当作损伤识别准确率。
2. **轻量 GCN/GAT/GraphSAGE**：用于检验 PS 点空间关系是否带来超出 MLP/TCN 的增益。需要固定邻接规则或明确距离阈值，并分别测试 FE 内点、FE 外点和未见点位布局。
3. **FEM 特权教师和知识蒸馏**：只有在动力边界、激励、阻尼以及教师输入和学生输入严格分离后启用。教师输出只应是可由观测推断的状态概率、区域 token、点关系或重构目标。
4. **FEM + 物理损失**：可在垂向位移参考一致性、空间平滑、区域聚集性和观测算子一致性上施加约束；不能把未经验证的动力方程直接当作真实 InSAR 物理。
5. **FEM + 条件域适配**：在 MMD/CORAL/DANN 完成后再加入 JDA、条件 MMD 或 NCORAL；目标域条件必须来自高置信伪标签或独立工程弱证据，并报告伪标签负迁移。

### 12.4 不适合作为当前正式主表的模型

| 路线 | 不纳入当前主表的原因 |
|---|---|
| 原论文固有频率输入的 DNN | 输入模态不是垂向 InSAR；可重建为 InSAR-like MLP，但不能直接复用其频率结果 |
| 原论文载荷/边界条件输入的 CNN 场代理 | 部署端不可得，标签是应力场而非区域状态；只能做重构扩展 |
| 原论文完整 FE 网格输入的 GNN | 完整网格、材料和边界条件属于训练期物理信息，不是部署端 PS 观测 |
| IEEE 视觉测量 + FEM 刚度更新 | 正文细节未完全核验，且输入/标签与 InSAR 状态任务不等价 |
| 仅在同分布 FEM 测试集上报告的模型 | 不能证明仿真到真实 InSAR 的迁移能力；最多作为 source-only 能力基线 |
| 只使用加速度、应变或高频车辆响应的模型 | 不能直接作为 InSAR 部署模型；除非统一生成可比的 FEM-InSAR-like 垂向观测 |

### 12.5 推荐的 FEM 深度模型实验矩阵

```text
组 A：FEM 源域监督
A0  Dummy/先验 + 温度趋势 + FEM 观测拟合
A1  FEM-InSAR-like MLP/ANN
A2  FEM-InSAR-like 1D CNN/TCN
A3  FEM-InSAR-like GRU/LSTM
A4  FEM-InSAR-like 轻量 GCN/GAT（第二阶段）

组 B：仿真到真实迁移
B0  Source-only
B1  Source-only + CORAL/MMD
B2  Source-only + NCORAL/NCA
B3  Source-only + DANN
B4  Source-only + 条件 MMD/JDA（第二阶段）

组 C：物理和特权扩展
C0  物理观测算子 + Source-only
C1  物理观测算子 + CORAL/MMD/DANN
C2  sparse-to-field 多任务重构
C3  FEM teacher -> InSAR student KD（可选）
```

所有模型共享以下条件：同一 `structural_state_id` 划分；同一输入字段白名单；同一窗口长度和日期处理；同一噪声、缺测、质量退化和未见点位布局；同一训练预算；随机种子 `13, 29, 42, 71, 101`。评价同时报告源域未见状态、目标域适配、目标域 final test、区域异常 AUCPR、事件窗口 recall、误报数、提前量、空间聚集性、形变重构误差和校准指标。

### 12.6 本轮补充检索的最终结论

1. **有限元数据训练深度学习模型是可行且有文献先例的**，但论文中的 FEM 往往承担不同角色：状态/标签生成器、响应模拟器、场代理求解器、图结构生成器或参数更新工具，不能笼统称为同一种“FEM 深度学习模型”。
2. **最适合当前研究正式主表的新增路线**是 `FEM-InSAR-like MLP/ANN source-only`，其方法依据主要来自 Lee et al. 2023；随后配套加入 `1D CNN/TCN`、`GRU/LSTM`、`CORAL/MMD` 和 `DANN`，以区分网络结构增益与仿真到真实域适配增益。
3. **最适合作为第二阶段扩展**的是 sparse-to-field CNN、轻量 GNN、FEM 特权教师/关系蒸馏和条件域适配。Bolandi 与 Maurizi 的工作主要支撑场重构和空间关系建模，不应直接包装为当前区域状态识别主模型。
4. **ACI T 梁 ANN 和 Fernandez-Navamuel 等桥梁 FEM 监督学习论文值得继续获取全文**，但在输入、标签和实测验证尚未完全核验前，只能作为候选文献，不能引用其具体性能数字或宣称已完成公平复现。
5. **IEEE 2025 FEM 刚度更新论文适合作为扩展参考而不是直接基线**；视觉输入和刚度参数识别与真实垂向 InSAR 学生接口不一致，必须经过观测域重建才能比较。

因此，新增有限元深度模型后，当前最小可发表闭环更新为：

```text
温度/FEM 物理拟合
-> InSAR-only MLP/GRU/TCN
-> FEM-InSAR-like MLP/ANN source-only
-> FEM-InSAR-like CNN/TCN 与 GRU/LSTM
-> CORAL/MMD、NCORAL/NCA、DANN
-> 物理观测算子成对消融
-> 可选 sparse-to-field/GNN/KD
-> 真实 PS 区域异常、重构、校准和事件级验证
```

该闭环回答的是“有限元状态信息能否通过可部署的垂向 InSAR 观测接口迁移到真实目标域”，而不是简单比较不同论文在不同传感器和不同标签上的原始准确率。
